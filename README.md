# Executive KPI Dashboard with Row-Level Security (Power BI)

## Project Overview

This project focuses on building an executive-level dashboard to monitor business performance using key financial metrics. The objective was to create dynamic KPIs, visualize profit trends, and implement Row-Level Security (RLS) to control data access based on user roles.

## What I Did

* Loaded financial data and created relationships between tables
* Developed key performance indicators (KPIs) including Total Profit, Profit Margin %, and Year-over-Year (YoY) Growth
* Designed an executive dashboard with interactive visualizations
* Implemented Row-Level Security to restrict data access by region
* Tested security roles using the "View as Role" feature in Power BI

## How I Did It

* Used Power BI for data modeling and visualization
* Created DAX measures to calculate financial KPIs
* Built advanced visuals such as waterfall and ribbon charts
* Created a Region table to manage user-based data access
* Configured and validated RLS settings for secure reporting

## Result

* Successfully created an executive dashboard displaying key financial metrics
* Visualized monthly profit changes and segment performance trends
* Implemented secure data access for regional managers
* Demonstrated practical skills in Power BI data modeling, KPI creation, and security implementation

## Tools Used

* Power BI
* Power Query
* DAX
* Data Visualization
* Row-Level Security (RLS)
